# Documents Organization

This folder contains all project documentation organized into logical categories:

## 📁 Folder Structure

### 🚀 **deployment/**
- Deployment guides and automation scripts
- Contains documentation for setting up and deploying the application

### 🔧 **implementation/**
- Implementation documentation and change logs
- Feature implementation guides and technical details
- Contains:
  - `IMPLEMENTATION_CHANGES.md` - Change tracking
  - `IMPLEMENTATION_COMPLETE.md` - Completion status
  - `IMPLEMENTATION_STEPS.md` - Step-by-step implementation
  - `EFFORT_TRACKING_IMPLEMENTATION.md` - Effort tracking features
  - `REVENUE_FORECASTING_IMPLEMENTATION.md` - Revenue forecasting features

### 📖 **guides/**
- User guides and quick start documentation
- Contains:
  - `ONE_HOUR_QUICK_START.md` - Quick start guide
  - `QUICK_START.md` - Basic quick start
  - `QUICK_TEST_GUIDE.md` - Testing guide
  - `UPGRADE_PLAN.md` - Upgrade instructions

### 🔧 **fixes-and-updates/**
- Bug fixes, patches, and update documentation
- Contains:
  - `API_FIX_DOCUMENTATION.md` - API-related fixes
  - `FIXES_SUMMARY.md` - Summary of all fixes
  - `GEMINI_MODEL_FALLBACK.md` - Model fallback implementation

### ✨ **features/**
- New feature documentation and specifications
- Contains:
  - `VISUALIZATION_IMPROVEMENTS.md` - UI/visualization enhancements

### 🖼️ **assets/**
- Images, logos, PDFs, and other media files
- Contains:
  - Logo images (practus_image.jfif, practus_logoo.jpeg)
  - Screenshots and diagrams
  - PDF documentation

### ⚙️ **config/**
- Configuration files and service definitions
- Contains:
  - `nginx-practus-ai.conf` - Nginx configuration
  - `practus-backend.service` - Backend service configuration
  - `practus-frontend.service` - Frontend service configuration

## 📝 Note

The main project documentation (`README.md`, `PRD.md`) remains in the root directory for easy access, as these are frequently referenced entry points for the project.
